## toml（BinaryMuse/toml-node）

- canonical source：`https://github.com/BinaryMuse/toml-node`
- tag：`v5.0.0`（lightweight tag）
- revision：`ccd8b103f08bea6d39541271b1e6c3dba9e73275`
- package：`toml@5.0.0`（MIT）
- npm：latest `5.0.0`，`gitHead` 与 tag 提交一致
- engines：`node >= 20`；零 runtime 依赖
- inspected：
  - `package.json`
  - `index.js`
  - `index.d.ts`
  - `src/toml.pegjs`
  - `lib/compiler.js`
  - `lib/parser.js`（文件头声明 `@generated by Peggy 5.1.0`）
  - `README.md`
  - `CHANGELOG.md`
  - `test/test_toml.js`
- observed：
  - 公开 API 只有 `parse(input, options)`；没有 stringify；
  - 入口把字符串交给 Peggy 生成的 parser，再由 `compiler.compile` 收成 JS 对象；
  - 表用 `Object.create(null)`，容器用 `WeakSet` 标记所有权（CHANGELOG 指向 GHSA-v5mp-jgw5-2x6j）；
  - 数组 / 内联表默认 `maxDepth: 500`，超限抛带 `line`/`column` 的普通 Error（CHANGELOG 指向 GHSA-82x6-q7mm-w9cf）；
  - Integer 节点在编译期先当 BigInt；默认超出 `Number` 安全整数就抛错，`bigint: true` 才整表返回 BigInt；超出 int64 无论哪种模式都抛；
  - 默认 offset date-time 是 `Date`，local date/time 是字符串；`useTemporal: true` 才走 Temporal，可经 `temporal` 注入 polyfill；
  - PEG 里 `validateDate` / `validateTime` 会拒绝非法日历日；
  - README 自称 toml-test 702/708，本轮未跑，不当成验收事实。

## smol-toml

- canonical source：`https://github.com/squirrelchat/smol-toml`
- tag：`v1.8.0`（lightweight tag）
- revision：`6d0f4774700c40ce8b5794934eb771870a9a93d3`
- package：`smol-toml@1.8.0`（BSD-3-Clause）
- npm：latest `1.8.0`，**未暴露 `gitHead`**；身份靠 tag + `package.json` version `1.8.0` + 提交 SHA
- engines：`node >= 18`；零 runtime 依赖；条件导出 `import` / `require`
- inspected：
  - `package.json`
  - `src/index.ts`
  - `src/parse.ts`
  - `src/extract.ts`
  - `src/primitive.ts`
  - `src/struct.ts`
  - `src/stringify.ts`
  - `src/date.ts`
  - `src/error.ts`
  - `src/util.ts`
  - `README.md`
  - `test/dos.test.ts`
- observed：
  - 公开 API 是 `parse` / `stringify` / `TomlDate` / `TomlError`；
  - 手写指针递归下降：`[` / `[[` 切表，否则 `parseKey` + `extractValue`；
  - 嵌套结构默认 `maxDepth: 1000`，耗尽抛 `TomlError`；stringify 同上限；
  - `integersAsBigInt` 为 `true` 时全部整数变 BigInt，为 `'asNeeded'` 时只把不安全整数升 BigInt，默认不安全整数抛错；
  - 解析日期一律 `TomlDate`（`Date` 子类）；不在 parse 路径发 Temporal；stringify 可认 Temporal；
  - README 写明 `2023-02-30` 会被 JS `Date` 滚成 `2023-03-02`，本轮按源码记录，未复跑；
  - `__proto__` 键用 `Object.defineProperty` 落自己的可写属性；
  - `TomlError` 带 `line` / `column` / `codeblock`；
  - stringify 忽略对象上的 `null`/`undefined`，数组里的 `null`/`undefined` 与 function/symbol 会拒绝。
