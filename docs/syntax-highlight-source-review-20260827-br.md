## PrismJS

- canonical source：`https://github.com/PrismJS/prism`
- revision：`76dde18a575831c91491895193f56081ac08b0c5`
- package：`prismjs@1.30.0`
- provenance：GitHub tag `v1.30.0` 指向本提交。npm `1.30.0` 的 `gitHead` 是父提交 `93cca40b364215210f23a9e35f085a682a2b8175`（`npm pkg fix`），在 canonical remote 可达且比 tag 落后 1 个 commit。本文绑定官方 Release tag，不把 npm `gitHead` 写成同一 SHA。
- inspected：
  - `package.json`
  - `prism.js`（concatenated core + markup + css + clike + javascript + file-highlight）
  - `SECURITY.md`
  - `README.md`
- observed：
  - default `prism.js` concatenates core with markup/css/clike/javascript grammars and the file-highlight plugin;
  - `highlight(text, grammar, language)` tokenizes then `Token.stringify(util.encode(tokens), language)` and throws when `grammar` is missing;
  - `util.encode` replaces `&`, `<`, and `\u00a0` only;
  - `highlightAllUnder` queries `code[class*="language-"]` / `lang-` variants; `manual` defaults false and auto-runs `highlightAll` after load;
  - worker highlighting is off unless `async === true` and `Worker` exists;
  - bundled file-highlight loads `pre[data-src]` with `XMLHttpRequest`;
  - package engines declare Node `>=6`.

## highlight.js

- canonical source：`https://github.com/highlightjs/highlight.js`
- revision：`f7f7d3803bd898e37c017ffb881317f0cde04a70`
- package：`highlight.js@11.12.0`
- provenance：GitHub tag `11.12.0`、package version 与 npm `gitHead` 指向同一提交
- inspected：
  - `package.json`
  - `src/highlight.js`
  - `src/stub.js`
  - `src/lib/html_renderer.js`
  - `src/lib/html_injection_error.js`
  - `src/lib/utils.js`
  - `tools/build_node.js`
  - `SECURITY.md`
  - `README.md`
- observed：
  - new `highlight(code, {language, ignoreIllegals})` defaults `ignoreIllegals` to true; the 10.7 positional API is deprecated;
  - `highlightAuto` scores registered languages and always includes a plaintext candidate; its internal `_highlight` passes `ignoreIllegals=false`;
  - `highlightElement` reads `textContent`, warns (and optionally throws `HTMLInjectionError`) when the block already has element children, then writes `innerHTML` and `dataset.highlighted`;
  - `highlightAll` uses `cssSelector` default `pre code` and defers until `DOMContentLoaded` when the document is still loading;
  - `SAFE_MODE` defaults true and turns fatal parse errors into escaped plaintext;
  - `escapeHTML` encodes `&`, `<`, `>`, `"`, and `'`;
  - source `package.json` has no `exports`; Node/ESM `exports` (`.`, `./lib/core`, `./lib/common`, `./lib/languages/*`) are generated by `tools/build_node.js`;
  - package engines declare Node `>=12.0.0`.
